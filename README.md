# Temka Studio — готовый пакет для Vercel

Это сайт студии, **не исходники лаунчера**. Главное: `index.html`, `styles.css`, `app.js`, `site-config.js`, `hardware.css`, `hardware-data.js`, `hardware-check.js`, `assets/`, `vercel.json`.

- Автор: temka_play. Fantazia RP 3D — Godot. Официальный Telegram сохранён.
- Нет ИИ-картинок, профиля сайта и фиктивной регистрации.
- Локальный вишлист без почты. Проверка ПК — предварительные требования, без FPS.
- Каталог 321 GPU и 503 CPU; методика и ограничения в `HARDWARE.md`.
- Резервная Windows-ссылка — **реальный опубликованный 1.5.5**. После публикации 1.5.6 сайт получит новую ссылку через GitHub API. Нельзя заранее подменять её на несуществующий установщик.

Полная инструкция: `НА-VERCEL.md`.

Pages workflow убран из этого Vercel-пакета, чтобы загрузка репозитория не запускала лишнюю публикацию GitHub Pages. npm и сборка не нужны. Не загружай сюда backend, лаунчер, EXE, node_modules и секреты.

Локальный просмотр: `python3 -m http.server 8080` из этой папки. Проверка ПК и вишлист работают локально; запрос к GitHub нужен только для обновления ссылки на скачивание.

Сайт из чата не был развёрнут в твоём аккаунте. Постоянный адрес появится после твоего Deploy.
