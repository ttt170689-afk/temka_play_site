# Temka Studio — отдельная страница Fantazia RP 3D

Статический сайт, без сборки и сервера приложений. Главная: index.html. Страница игры: fantazia.html.

## Добавлено

- Все пять входов в Fantazia на главной открывают отдельную страницу: герой, обложка, название, ссылка и новость. Это обычные ссылки — переход работает без JavaScript, назад и в новой вкладке.
- Название Fantazia RP 3D, цена «Бесплатно», статус «Скоро».
- Раздел скриншотов пока честно пуст: «Скриншоты скоро». Скриншоты игры от пользователя ещё не поступили. Чужие/ИИ-изображения не добавлялись.
- Ниже — «Описание» и «Характеристики», в обоих «Скоро будут».
- Ссылки назад и на официальный Telegram. Один автор: temka_play; создатель temka_play_official. Движок — Godot.
- Вишлист общий с главной в пределах браузера; прежний ключ temka-site-wishlist-v1 сохранён. Без email, без обещаний рассылки/синхронизации с лаунчером.

Кнопок скачивания или запуска Fantazia нет. Проверка ПК, сайт-профиль и поиск друзей не возвращались. Друзья остаются в лаунчере. Скачивание самого лаунчера на главной и существующая проверка GitHub Releases не менялись в рамках этой задачи.

## Выложить

Архив `Temka-Studio-Fantazia.zip` — **для вкладки «Сайт / браузер» в Temka Publisher 1.0.8**. В старых Publisher 1.0.6/1.0.7 и во вкладке «Лаунчер» его загружать нельзя.

Самый простой способ: открой «Сайт / браузер» → выбери этот ZIP → «ОБНОВИТЬ САЙТ» → подтверди полную замену. Номер версии не нужен. Программа отправит сайт в `ttt170689-afk/temka_play_site` и отдельно проверит Production-деплой Vercel. «Файлы в GitHub» ещё не означает готовность сайта. История и существующая .github сохраняются; файлы сайта, которых нет в ZIP, удаляются. Нужен полный ZIP, не архив только новых страниц.

Без Publisher:

Замени файлы в корне репозитория `ttt170689-afk/temka_play_site` содержимым ZIP, сохрани структуру assets. Важно добавить новые fantazia.html, fantazia.css и fantazia.js, а также заменить index.html/app.js/vercel.json. Проект Vercel: Other, без Build/Install, Output `.`. При включённом автодеплое дождись Ready после коммита.

`cleanUrls: true` позволяет Vercel показывать страницу как /fantazia. Ссылки в HTML используют fantazia.html: они работают также на простом статическом сервере; Vercel сам обработает чистый адрес. Реальный деплой Vercel в этом чате не выполнялся.

При ручной загрузке удали оставшиеся hardware.css, hardware-data.js, hardware-check.js, HARDWARE.md и тесты checker отдельно: сама загрузка файлов через GitHub их не удалит. Новая вкладка Publisher делает полную замену сайта и удаляет отсутствующие в ZIP старые файлы автоматически.

## Фото позже

Когда автор пришлёт свои игровые скриншоты, добавим их в assets и заменим блок project-gallery-empty настоящей галереей. Скриншоты лаунчера/ошибок из переписки не использовались как изображения игры.

## Проверки

См. TEST-REPORT.md. Для локального просмотра: `python3 -m http.server 8080`, затем открывай сайт с этого сервера. Тестовый сценарий tests/fantazia-smoke.cjs требует установленный Playwright/Chromium; SITE_TEST_URL задаёт адрес тестируемого сайта, PLAYWRIGHT_PATH — путь к библиотеке при отдельной установке. Они не нужны посетителям или Vercel.
